CODING SESSION RULES

1. Inspect the project before making changes.
2. Do not reread files already inspected unless necessary.
3. Maintain a record of completed tasks.
4. Never repeat a successful test without a reason.
5. Do not repeat completed subtasks.
6. Use targeted file reads instead of scanning the
   entire project repeatedly.
7. Preserve existing implementation decisions.
8. Before executing a tool, check whether its result
   is already available in the conversation.
9. Update PROJECT_STATE.md after meaningful milestones.
10. Verify only the changes affected by the current task.
